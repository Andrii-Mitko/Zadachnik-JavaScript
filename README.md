# Zadachnik JavaScript

A personal JavaScript practice repository containing exercises and coding
challenges from beginner to advanced levels.

## About

This repository is a collection of JavaScript exercises created during my
self-study and Full-Stack Developer training.

It contains practical tasks organized by levels and modules, helping to
strengthen programming fundamentals, develop problem-solving skills, and gain
hands-on experience with JavaScript.

The repository is intended as a learning resource and reference for revisiting
concepts and practicing different approaches to solving problems.

## Topics Covered

- JavaScript fundamentals
- Variables, data types, and operators
- Conditional statements and loops
- Strings and numbers
- Arrays and array methods
- Objects and object methods
- Functions and callbacks
- Array iteration methods (`map`, `filter`, `reduce`, `forEach`)
- Sorting and data transformation
- DOM manipulation
- Events and event handling
- Working with HTML elements
- Generating HTML dynamically
- Practical algorithms and problem-solving

## How to Use

- Browse the `js/task/` directory to explore exercises organized by levels and
  modules.
- Explore `js/tasks-Fun/` for additional programming challenges.
- Read the task descriptions and try solving each exercise independently.
- Compare different solutions and experiment with alternative approaches.
- Use the repository as a reference when revisiting JavaScript concepts.
